## Known constraints

- **Edge function resets:** Figma Make reverts `supabase/functions/server/index.tsx` to a stub on every save. All backend logic must go in the React app or directly in Postgres (triggers, functions, views, pg_cron). Never put migration or business logic in the edge function.
- **No service-role key in client code** — all writes go through the Supabase anon key with RLS enforcing access.
- **Single file architecture** — the entire app lives in `src/app/App.tsx` due to Make platform constraints. Split into logical sections with `// ─── Section ───` comment dividers.
- **Currency:** Naira only, via `formatNaira()`. Never use `toFixed(2)` directly anywhere else.
- **Dates:** via `formatDate()` only. Display as `DD Month YYYY`.
